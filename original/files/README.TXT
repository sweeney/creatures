Creatures version 1.0, April 1996

To install Creatures, simply run the program setup.exe found on the
distribution disk. You can do this from the Program Manager. The Install
program will automatically create a group and icon.

Creatures runs best on a fast computer. Although it can be run on a 386
machine, the computational intensive nature of the simulation means
that we have to recommend at least a 486 33MHz. More powerful machines
will result in even better simulation times. For example on a 120 MHz
Pentium with a fast graphics card, the simulations are at least an order
of magnitude faster and you will find your work with Creatures much more
intersting as a result.

Happy simulating!
